# 三维模型显示模块说明

## 1. 模块目标
本模块用于在上位机中显示带颜色的装配体模型，优先支持 GLB / GLTF 与 OBJ + MTL，STL 作为几何 fallback。

## 2. 文件结构
- `src/ui/widgets/model_loader.py`：模型加载与格式优先级控制。
- `src/ui/widgets/model_viewer.py`：Qt 三维显示控件 `ModelViewer`。
- `tools/model_viewer_demo.py`：独立演示程序。

## 3. 模型文件命名（必须英文）
运行时只读取以下英文路径：
- `assets/models/assembly_model.glb`
- `assets/models/assembly_model.gltf`
- `assets/models/assembly_model.obj`
- `assets/models/assembly_model.mtl`
- `assets/models/assembly_model.stl`
- `assets/models/device_model.stl`

> 不建议使用中文文件名作为程序路径。

SolidWorks 原始文件可放入 `assets/models/source/` 备份，但不参与运行时加载。

## 4. 加载优先级
1. `assembly_model.glb`
2. `assembly_model.gltf`
3. `assembly_model.obj` + `assembly_model.mtl`
4. `assembly_model.stl`
5. `device_model.stl`
6. fallback 简化模型

任意格式加载失败后会自动尝试下一个格式，避免主程序崩溃。

## 5. 支持能力说明
- GLB / GLTF：遍历 scene 内多个 geometry/node，尽量保留装配关系与基础颜色。
- OBJ + MTL：支持多 mesh/group，尽量读取材质颜色；MTL 缺失时使用默认颜色。
- STL：支持作为稳定几何 fallback（通常不保留 SolidWorks 原始颜色）。
- 不直接读取 SolidWorks 原生文件。

## 6. 主题与交互
- `set_theme("dark")` / `set_theme("light")`。
- 鼠标交互由 `pyqtgraph.opengl.GLViewWidget` 提供：旋转、缩放、平移。
- `update_force_vectors(fx, fy, fz)` 可更新 Fx/Fy/Fz 三方向力指示线。

## 7. 对外接口
`ModelViewer` 主要接口：
- `load_best_available_model()`
- `reload_model()`
- `set_theme(theme)`
- `update_force_vectors(fx, fy, fz)`
- `get_status()`

`get_status()` 返回加载类型、路径、零件数量、是否 fallback 等状态。

## 8. Demo 运行
```bash
python tools/model_viewer_demo.py
```

Demo 提供按钮：
- 深色主题
- 浅色主题
- 重新加载模型
- 模拟 Fx/Fy/Fz

## 9. 模型无法加载时排查
1. 检查 `requirements.txt` 依赖是否安装完整。
2. 检查模型路径与文件名是否为英文且与规范一致。
3. 检查 GLB/GLTF/OBJ/STL 文件是否损坏。
4. 观察控制台日志（会输出每一级加载尝试与失败原因）。
5. 若 OpenGL 不可用，界面将降级为简化提示视图。

## 10. 真实 GLB 文件说明（本轮修复）
- 真实模型文件来源：仓库 `main` 分支中的 `assembly_model.glb`。
- 当前测试分支标准运行路径：`assets/models/assembly_model.glb`。
- 程序会优先加载 `assembly_model.glb`；仅当 GLB 解析失败时，才依次尝试 GLTF、OBJ、STL。
- Demo 已改为基于 `REPO_ROOT` 拼接模型目录，确保从任意工作目录启动都能定位到模型文件。
- 程序运行路径不建议使用中文文件名；模型文件名统一使用英文。

## 11. 三维交互操作说明（本轮增强）
- 左键拖拽：旋转模型。
- 滚轮：缩放模型（优先按鼠标所在区域做近似焦点缩放，而非固定画面中心）。
- 中键拖拽 / 右键拖拽 / Shift + 左键拖拽：平移模型。
- 双击视图：重置视角。
- 预设视角按钮：前视图、后视图、左视图、右视图、顶视图、底视图。
- 模型侧躺：将模型切换到侧卧姿态（显示层变换，不修改原始几何文件）。
- 恢复正放：恢复到默认正放姿态（显示层变换重置）。
- 深色主题与浅色主题切换仅更新显示样式，不重新解析模型文件。

## 13. 接近 SolidWorks 的鼠标交互（本轮）
- 鼠标滚轮滚动：按鼠标所在区域进行缩放（近似 zoom-to-cursor），不是固定围绕窗口中心。
- 按住鼠标滚轮拖动：自由旋转模型，可观察背面、底面与侧躺姿态。
- Shift + 按住鼠标滚轮拖动（或 Ctrl + 按住鼠标滚轮拖动）：执行 roll 侧滚旋转，实现模型侧躺/翻转观察。
- 鼠标右键拖动：平移模型视野中心，不改变模型姿态。
- 鼠标左键双击：重置视角（重新居中、恢复默认距离/视角、清除侧滚姿态）。

说明：Demo 中按钮仅保留“深色主题、浅色主题、重新加载模型、模拟三维力”，模型观察主要通过鼠标完成，不依赖视角按钮。


## 14. 细长夹钳模型的局部放大优化
- 针对细长夹钳（关键观察点在顶端）优化了滚轮缩放行为：滚轮不仅改变距离，还会同步调整观察中心。
- 当鼠标停在夹钳顶端附近滚轮放大时，顶端区域会逐渐向画面中心靠近，减少反复手动平移。
- 缩放过程使用平滑插值（lerp）避免跳动，并限制最小/最大相机距离，避免模型消失或缩放失控。
- 关键可调参数包括：`zoom_sensitivity`、`min_distance`、`max_distance`、`zoom_to_cursor_strength`、`zoom_center_lerp`、`pan_sensitivity`。
- 模型观察优先通过鼠标完成：滚轮局部放大、按住滚轮拖动旋转、Shift/Ctrl+滚轮拖动侧滚、右键平移、左键双击重置。
